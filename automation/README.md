# Automation Layer

`nova_act_controller.py` is the browser automation integration point for Service Agent.

For hackathon demo reliability, it returns a deterministic execution trace while preserving the same interface expected by live Nova Act execution.

To replace with live automation:

1. Establish authenticated browser session lifecycle
2. Bind Nova Act model outputs to browser action primitives
3. Persist evidence artifacts (screenshots, request traces)
4. Return submission reference generated by target portal
